CSS Box-Sizing Comparison

Comparing content-box vs border-box with equal width (320px), padding (30px), and border (10px).

box-sizing: content-box

Width: 320px | Padding: 30px | Border: 10px

Actual Rendered Width = 400px
(320px width + 60px padding + 20px border)

box-sizing: border-box

Width: 320px | Padding: 30px | Border: 10px

Actual Rendered Width = 320px
(Padding & border absorbed inside width)

How Box-Sizing Affects Element Dimensions:

Under content-box (the browser default), padding and borders are added on top of the specified element width, causing the total rendered box to expand beyond 320px to 400px.

Under border-box, padding and border values are absorbed inside the declared width, maintaining a fixed overall width of 320px for predictable responsive web layouts.
