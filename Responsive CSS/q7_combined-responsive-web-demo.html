Responsive Design

Responsive design allows a website to adjust its layout, content, and elements according to the screen size of the device.

CSS Grid, Flexbox, media queries, and flexible units help create responsive websites.

CSS Cheat Sheet

Flexbox

Used for flexible one-dimensional layouts.

Grid

Used for two-dimensional layouts.

Media Query

Changes styles according to screen size.
